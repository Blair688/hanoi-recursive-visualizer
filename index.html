汉诺塔的目标很简单：把左边 A 柱上的全部圆盘， 在不违反规则的情况下全部移动到右边 C 柱。 它也是理解递归分解最直观的例子之一。

核心思想 把一个复杂问题，拆成同样结构的小问题

第一部分 · 认识问题

汉诺塔是什么？

汉诺塔是一个经典递归问题。规则不复杂，但每一步都必须为后面的移动保留正确顺序。

  1. 01
    一次只能移动一个圆盘

    不能同时拿起两个圆盘，也不能一次拖动整摞圆盘。

  2. 02
    只能取柱子最上面的圆盘

    下面的圆盘被压住时不能移动，必须先处理它上方的盘子。

  3. 03
    大盘永远不能压在小盘上

    每根柱子从上到下都必须保持“小盘在上、大盘在下”。

  4. 04
    最终全部到达目标柱 C

    A 柱清空，所有圆盘按原顺序完整落在 C 柱上。

  5. 05
    最少需要 2n−1 步

    圆盘数为 n 时，最优解法的移动次数会随 n 快速增长。

一句话记忆

移动时永远守住“大盘在下，小盘在上”

为了把最大的盘子移到目标柱，必须先把它上面的小盘子全部暂时移开。 这个过程，正好就是递归要解决的问题。

第二部分 · 看懂递归

移动 n 个盘，其实只需要想三件事

先不要盯着每一步。把问题缩小一层，递归结构就会变得非常清楚。

  1. 1
    先把上面 n−1 个盘移走 move_tower(n−1, start, aux, dest)

    让最大的盘上方变空，这样它才能移动。

  2. 2
    再移动最大的第 n 个盘 start → dest

    这一步是当前问题里唯一一次直接移动最大盘。

  3. 3
    最后把 n−1 个盘移回目标柱 move_tower(n−1, aux, dest, start)

    小问题完成后，大问题自然就完成了。

n = 3 的递归拆解

从一次调用，展开成一棵调用树

move_tower(3, A, C, B)
move_tower(2, A, B, C)
move_tower(1, A, C, B)
移动 2 号盘：A → B
move_tower(1, C, B, A)
直接移动 3 号盘：A → C
move_tower(2, B, C, A)
move_tower(1, B, A, C)
移动 2 号盘：B → C
move_tower(1, A, C, B)

从最大的问题开始：把 3 个盘从 A 移到 C。

展开规则 
void move_tower(int n, char start, char dest, char aux)
{
  if (n == 1)
  {
    printf("Move disk1 from %c to %c\n", start, dest);
  }
  else
  {
    move_tower(n - 1, start, aux, dest); // 左递归
    printf("Move disk%d from %c to %c\n", n, start, dest); // 直接移动
    move_tower(n - 1, aux, dest, start); // 右递归
  }
}
