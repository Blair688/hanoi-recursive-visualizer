# 汉诺塔递归可视化

一个基于原生 HTML、CSS 和 JavaScript 的汉诺塔递归演示程序。页面可以逐步展示圆盘移动、递归调用栈、调用展开路径与对应的 C 语言递归代码。

## 功能

- 支持输入 `1-64` 层圆盘
- 支持自动演示、暂停、继续和单步执行
- 实时显示递归调用栈与递归展开过程
- 点击移动记录、调用栈或递归展开中的步骤可以回放到对应状态
- 可拖动调整动画区、右侧栏和代码区尺寸
- 窄屏与浏览器缩放时自动调整布局

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务器。

## 文件

- `index.html`：页面结构
- `styles.css`：页面样式和响应式布局
- `script.js`：汉诺塔递归状态机、动画和交互逻辑
