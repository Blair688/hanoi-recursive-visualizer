# 汉诺塔递归可视化

一个基于原生 HTML、CSS 和 JavaScript 的汉诺塔递归教学程序。页面按照“问题介绍、递归原理、交互演示”三个阶段展开，并同步展示圆盘移动、递归调用栈、调用展开路径与对应的 C 语言递归代码。

## 功能

- 用简洁规则说明汉诺塔的目标、限制和最少步数
- 用进入视口自动播放的递归树展示 `n=3` 的调用拆解过程
- 支持输入 `1-64` 层圆盘
- 提供手动逐步和自动演示两种模式，默认进入手动模式
- 手动模式支持“上一步 / 下一步”，每次只移动一个圆盘；上一步带反向移动动画
- 自动模式支持播放、暂停、继续和 `1-6` 级速度
- 实时显示递归调用栈与递归展开过程
- 点击移动记录、调用栈或递归展开中的步骤可以回放到对应状态
- 悬停或点击圆盘可以查看该盘的全部相关步骤，并从浮层中直接跳转
- 可拖动调整动画区、右侧栏和代码区尺寸
- 窄屏与浏览器缩放时自动调整布局
- 页面滚动时提供错峰渐入、递归路径绘制和滚动进度反馈，并支持减少动态效果

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务器。

## 文件

- `index.html`：页面结构
- `styles.css`：页面样式和响应式布局
- `script.js`：汉诺塔递归状态机、动画和交互逻辑
